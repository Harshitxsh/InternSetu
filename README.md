# 🇮🇳 InternSetu — AI Smart Allocation & Skill Bridge Engine

> **Smart India Hackathon (SIH) Nationals — Software Category**  
> *Developed for the Ministry of Corporate Affairs (MCA), Government of India.*

**InternSetu** is a full-stack, AI-powered allocation and gamified career-pathway platform designed to modernize the Prime Minister’s Internship Scheme (PMIS). It solves the bottlenecks of manual candidate screening by combining **Sentence-BERT semantic role matching**, **resume anti-fluff verification**, **affirmative equity normalization**, and **fairness-driven Integer Linear Programming (ILP) optimization**.

---

## ✨ Key Features

* **🏛️ Official Government Gateway & Branding:** Tailored with official Ministry of Corporate Affairs styling, real-time DBT stipend tracking, and affirmative equity filters.
* **🔍 Multi-Stage Verification Pipeline:** Automated checks combining OCR resume parsing, anti-hallucination credibility scoring, and strict government eligibility rules.
* **🧠 Hybrid 100-Point Match Engine:** Computes deep semantic compatibility using vector embeddings across technical skills, academic records, and project experience.
* **⚖️ Fairness-Aware Allocation (ILP):** Powered by Google OR-Tools to maximize corporate placement while enforcing social category quotas and regional diversity constraints.
* **🎮 Gamified "Skill Quests" Engine:** For candidates below the 85% allotment threshold, the system provides an interactive skill roadmap with real-time score boosting (`+X% Eligibility`) and celebratory milestones.

---

## 🚀 Tech Stack

* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide React, canvas-confetti
* **Backend API:** FastAPI / Flask, Python
* **AI & NLP:** Sentence-Transformers (`all-MiniLM-L6-v2`), scikit-learn, PyTorch
* **Optimization:** Google OR-Tools (ILP Solver)
* **Database:** SQLite (Offline Mode) / Supabase PostgreSQL (Cloud Mode)
